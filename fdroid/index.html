Sigil for Android

Voice calls and end-to-end encrypted chat over sQUIC, as a device of your account. This page is an F-Droid repository: add it once and updates arrive like any other app's.

Add it to F-Droid

  1. Install F-Droid if you have not.
  2. Open Settings → Repositories, press +, and enter this address:
https://wave-cl.github.io/sigil-android/fdroid/repo

Then find Sigil under Latest, and install it.

Check you have the right repository

F-Droid pins this key the moment you add the repository. It should read:

A5 2C 1D F8 C3 34 79 C5 9D 63 DA 79 92 FB D6 5C
C7 E7 31 50 9C 61 D9 85 B3 41 13 5E 55 87 BE 7A

Or install the APK directly

Every version here is also attached to a GitHub release, signed with the same key — the two are the same file, and one upgrades over the other.
